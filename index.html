Warning signs to notice

Unexpected domain
A spelling change or extra word may be deceptive.
Missing HTTPS
An unencrypted connection is a warning, but HTTPS alone doesn't guarantee trust.
Pressure or urgency
Messages demanding immediate action can be suspicious.
Unexpected sign-in
Reach important services through their official app or typed address.

Project information

About PhishScale

A student-friendly cybersecurity awareness demo.

Project objective

PhishScale demonstrates how a web interface and a small Node.js backend can work together to support cybersecurity education. It provides basic URL-format checks, awareness content, and local demo campaign tracking.

Technology stack

HTML CSS JavaScript Node.js Express

Important limitations

This student demo does not query threat-intelligence databases, browse websites, send emails, collect credentials, or confirm that a website is safe. Use it for learning and demonstrations only.

For a real security product, add reviewed threat-intelligence APIs, secure server-side validation, authentication, privacy controls, and proper testing.
